feat(http): add spola.http HTTP/1.1 server on virtual threads

New standalone module with a strict RFC 9112 request parser, keep-alive,
pipelining, chunked in both directions, lazy 100-continue, request
smuggling and response splitting defences, limits and timeouts as values,
and graceful shutdown. Two majors remain open: malformed chunked bodies
can still yield the handler's response, and concurrent close() deadlocks.
