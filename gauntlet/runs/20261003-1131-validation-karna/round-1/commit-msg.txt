feat(validation): add spola.validation with composable validators

New standalone module replacing Jakarta Bean Validation: validators built
as plain Java from getters and Constraint values, no annotations or
reflection. Violations carry path, code and message (never the rejected
value), use the JSON codec's path notation, and are capped at 100 while
all are counted. Includes 27 built-in constraints, README and docs.
