fix(security): make hash upgrade conditional to keep password changes

InMemoryUserStore.upgrader(hasher) replaces a stored hash only while it
still needs a rehash, in one atomic step, so a login that is upgrading can
no longer undo a password change made at the same time. The docs and the
README example use the new wiring, and a test pins the race. Also cleans
up invisible characters in Names and the iteration digit limit.
